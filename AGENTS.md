# Baby Shark

Explores whether Claude Code can one-shot a music video for Pinkfong's "Baby
Shark" in a crude, mouse-drawn MS Paint style, inventing a story the repetitive
lyrics don't supply. Sibling of `../2026-09-aguita-amarilla`, which it takes the
style hints from.

- `prompt.md` is the one-shot prompt. Run it from the repository root.
- `reference/style.md` and the four drawings in `reference/frames/` are style
  hints from the "Mi agüita amarilla" MS Paint video.
- Work from the audio only, so the story is original rather than a copy of
  Pinkfong's video.
- `reference/song.mp3` is copyrighted and ignored. Rebuild it as described in
  the README.
- Put renders in `out/` (ignored).
